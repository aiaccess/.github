# .github

Default community health files for repositories maintained by [David Grudl](https://github.com/dg): issue templates, the pull request template, the contributing guide, the code of conduct, the security policy and the funding link.

GitHub uses a file from here in every repository that does not have its own copy (see [GitHub Docs](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file)).
